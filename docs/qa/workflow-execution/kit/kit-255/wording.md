1. **Notice** (the tab's log and one warning notification, in process and on the worker; `omicsCorrelationExclusionNotice`, `R/utils_workflow_omics_declarations.R`). One sentence per assay, then once the note on the per-group minimum.
   - One sample: "Correlation filter: in assay LCMS_Neg, sample B_6 did not reach the threshold of 0.5 (its best correlation with a replicate there is -0.015). Its values in LCMS_Neg are set to missing. It stays in the analysis of LCMS_Pos (it reached the threshold there) and GCMS (it was not tested there), and is not removed from the study." (only the assays where it reached the threshold or was not tested are named; an assay where it was also set missing is not)
   - A group left without a value in an assay: "In assay LCMS_Neg, no sample of group B has a value left, so comparisons with that group are not tested in LCMS_Neg."
   - A sample removed because no assay kept a value for it: "Sample B_6 had no remaining value in any assay and was removed from the study."
   - No correlation computable: "(no correlation with a replicate could be computed there)".
   - Several samples in one assay: "Correlation filter: in assay A, samples S1 (best correlation with a replicate there is R1), S2 (...) did not reach the threshold of T. Their values in A are set to missing. They are not removed from the study. They stay in the analysis of: S1 in B (it reached the threshold there); S2 in B (it reached the threshold there), C (it was not tested there)." (per sample, the assays where it reached the threshold or was not tested; as the code writes it, `R/utils_workflow_omics_declarations.R:1273-1276`)
   - Once: "Features in LCMS_Neg that met your minimum number of values per group before this step may now have fewer values in one group. The differential analysis tests each feature on the values that remain; a feature with no remaining values is not tested."
   - The kernel's "Removing N samples ..." message does not reach the tab (AUDIT-KIT-255-impl I03); the sentence above is the notice's.
