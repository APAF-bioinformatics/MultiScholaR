METHOD DETAILS  

Data analyses were performed with MultiScholaR; the software version and build are listed under 'Software and build'. 
SOP reference: [to be completed by the analyst].  

**Data import and protein quantification**

Protein-level label-free quantification was imported from the 'kit236' export, one quantity per protein and sample, with missing values kept as missing.

**Protein quality control and filtering**

Protein identifications were filtered to ensure high-confidence quantification 
and reliable downstream statistical analysis. 

**FASTA reference and protein accession cleanup**

Protein identifications were validated against the provided FASTA reference database to ensure accurate annotation.

Protein accessions were cleaned and validated to ensure accurate annotation and to select the best representative protein ID when multiple accessions were present. Duplicate protein entries were removed to prevent redundancy in quantification.

Proteins were then filtered on missing values within experimental groups. Intensities below the 
1st percentile of all intensities in the table were treated as missing. 
Within each group a protein failed if the share of its values that were missing exceeded the allowed share, 60% (shown rounded to three decimals); a protein was retained if the share of experimental groups in which it failed did not exceed the allowed share, 60% (shown rounded to three decimals).

Proteins appearing in only one replicate across all groups were also excluded 
to ensure measurement reproducibility and reliable quantification across biological 
replicates.

**Normalisation and batch effect correction**

Using the protein intensity matrix, zero values were replaced with NA to denote 
missing values. The data matrix was log (base 2) transformed and between-sample 
normalisation was performed using the 'cyclicloess' method from the 'limma' 
R package (Ritchie et al., 2015). This normalisation approach adjusts for 
systematic technical variation while preserving biological differences.

Whether RUV-III batch correction was applied is not recorded for this analysis.

At each stage of the data normalisation, the samples were checked for batch effects 
using principal component analysis (PCA) plots, density boxplots, relative 
log-expression (RLE) plots, and the distribution of Pearson correlation between 
replicate samples within groups. These quality control visualisations allow 
assessment of technical variation removal while ensuring biological signal is 
retained.

DIFFERENTIAL ABUNDANCE ANALYSIS

Differential abundance analysis of proteins was performed using the adjusted 
abundance matrix for the comparisons defined in the contrast table. The 'limma' R 
package (Ritchie et al., 2015) was used. A linear model was fitted using the formula '~ 0 + group' with the 
'lmFit' function, and p-values were calculated using the 'eBayes' function. 
A trended and robust empirical Bayes analysis was performed. The false discovery rate correction was applied to the 
moderated p-values by calculating the q-values (Storey, 2002). 
The standard empirical Bayes method was used to test for any deviation from zero log-fold-change. Significant differentially expressed proteins were defined as those 
with q-values less than 0.05.

Volcano plots of differentially expressed proteins across all groups are shown 
in Figure 3, with a threshold of q-value < 0.05 and no log fold-change 
threshold. Full details of all proteins are provided in the supplementary results
table DA_results_proteomics.xlsx within the Publication_tables folder.
