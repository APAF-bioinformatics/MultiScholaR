Missing values => Data Preprocessing and Normalization Intensities were log2-transformed; a value of zero was read as not detected and was not imputed, so a feature was tested only where it was measured, and a fold change can be underestimated when values fall below the detection limit in one group. Missing values (zeros or non-detects) were coded as NA to distinguish true absence from missing measurements.

empirical Bayes method => and p-values were calculated using the 'eBayes' function. A trended and robust empirical Bayes analysis was performed. The false discovery rate correction was applied to the moderated p-values by calculating the q-values (Storey, 2002). The standard empirical Bayes method was used to test for any deviation from zero log-fold-change. Significant differentially abundant lipids were defined as those with q-values less than 0.05.
