Multi-Assay Data Structure The dataset contains 2 assays: LCMS_Pos, LCMS_Neg. Each assay was processed and tested for differential abundance separately; the results of the 2 assays are reported together.
Data Preprocessing and Normalization Intensities were log2-transformed; a value of zero was read as not detected and was not imputed, so a feature was tested only where it was measured, and a fold change can be underestimated when values fall below the detection limit in one group.
ITSD Normalization Internal standard (ITSD) normalization was applied using the average_centered method with median aggregation across ITSD features. Internal standard features were removed after normalization.
Between-sample normalization was performed using the ‘cyclicloess’ method from the ‘limma’ R package (Ritchie et al., 2015) to account for systematic technical variation across samples.
Batch Effect Correction RUV-III batch correction was not applied. The analysis proceeded directly with normalized data for differential abundance analysis.
Quality Control At each stage of data normalization, samples were checked for batch effects using: • Principal component analysis (PCA) to visualize sample clustering • Density boxplots to assess distribution consistency • Relative log-expression (RLE) plots to detect systematic biases • Pearson correlation matrices to evaluate replicate consistency
Per-Assay Quality Metrics Per-assay quality control: the quality-control figures were drawn separately for each assay. The assays were required to contain the same samples.

Differential Abundance Analysis
DIFFERENTIAL ABUNDANCE ANALYSIS
Differential abundance of metabolites was tested separately within each assay, using the adjusted abundance matrix, for the comparisons defined in the contrast table (1 comparison: KO_vs_WT). The ‘limma’ R package (Ritchie et al., 2015) was used. A linear model was fitted using the formula ‘~ 0 + group’ with the ‘lmFit’ function, and p-values were calculated using the ‘eBayes’ function. A trended and robust empirical Bayes analysis was performed. False discovery rates were estimated as q-values (Storey, 2002); where they cannot be computed, Benjamini-Hochberg adjusted p-values are used. Each comparison was tested for any difference from zero log2 fold change. Differentially abundant metabolites were those with a q-value below 0.05.
Full details of all metabolites are provided in the supplementary results table DA_results_metabolomics.xlsx within the Publication_tables folder.

Pathway Enrichment Analysis
PATHWAY ENRICHMENT ANALYSIS
Pathway enrichment analysis was performed on the differentially abundant metabolites to identify significantly enriched metabolic pathways and biological processes. The analysis was conducted using the following parameters: • No fold change cutoff was applied to filter differentially abundant metabolites. • An adjusted FDR cutoff of 0.05 was used to identify significantly enriched pathways • The background metabolite set consisted of all identified metabolites that passed quality control filtering steps
The enrichment analysis was performed using KEGG pathway databases. Pathways were considered significantly enriched if they had an adjusted p-value less than 0.05 after multiple testing correction using the Benjamini-Hochberg method.
