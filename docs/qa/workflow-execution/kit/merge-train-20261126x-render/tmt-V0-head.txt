Data import and protein quantification
Protein-level quantification data was imported from Proteome Discoverer TMT workflow output. The data contains isobaric tag-based (TMT) quantification values for identified proteins across all samples. TMT-based quantification provides relative abundance measurements through reporter ion intensities in MS/MS spectra, with proteins already quantified at the protein level by the upstream Proteome Discoverer workflow.
Protein quality control and filtering
Protein identifications were filtered to ensure high-confidence quantification and reliable downstream statistical analysis.
FASTA reference and protein accession cleanup
Protein identifications were validated against a standard UniProt FASTA database, providing comprehensive protein metadata including evidence levels, reviewed status, gene names, and isoform information. This metadata was used to select the highest-quality protein identifications during accession cleanup.
Protein groups containing multiple accessions (separated by ‘;’ delimiters) were resolved by selecting the best representative protein based on protein evidence levels, sequence length, and database annotation quality. Quantitative values for proteins within the same group were aggregated using the ‘mean’ method, reducing 400 protein groups to 400 unique protein identifications. Duplicate protein entries were removed to prevent redundancy in quantification.
Proteins were then filtered on missing values within experimental groups. Intensities below the 0.1th percentile of all intensities in the table were treated as missing. Within each group a protein failed if the share of its values that were missing exceeded the allowed share, 80% (shown rounded to three decimals); a protein was retained if the share of experimental groups in which it failed did not exceed the allowed share, 50% (shown rounded to three decimals).
Proteins appearing in only one replicate across all groups were also excluded to ensure measurement reproducibility and reliable quantification across biological replicates. After quality control filtering, N/A proteins remained for normalisation.
Normalisation and batch effect correction
Using the protein intensity matrix, zero values were replaced with NA to denote missing values. The data matrix was log (base 2) transformed and between-sample normalisation was performed using the ‘cyclicloess’ method from the ‘limma’ R package (Ritchie et al., 2015). This normalisation approach adjusts for systematic technical variation while preserving biological differences.
RUV-III batch correction was not applied. The analysis proceeded directly with normalised data for differential abundance analysis.
At each stage of the data normalisation, the samples were checked for batch effects using principal component analysis (PCA) plots, box plots of the principal component scores, relative log-expression (RLE) plots, and the distribution of Pearson correlation between replicate samples within groups. These quality control visualisations allow assessment of technical variation removal while ensuring biological signal is retained.

The notch spans the median plus and minus 1.58 times the interquartile range divided by the square root of the number of samples in the group: as a rough guide, two groups whose notches do not overlap have medians that differ at about the 5% level (McGill, Tukey and Larsen, 1978). With fewer than about ten samples in a group the notch extends beyond the box and should not be read. Differential Abundance Analysis
DIFFERENTIAL ABUNDANCE ANALYSIS
Differential abundance analysis of proteins was performed using the adjusted abundance matrix for the comparisons defined in the contrast table. The ‘limma’ R package (Ritchie et al., 2015) was used. A linear model was fitted using the formula ‘~ 0 + group’ with the ‘lmFit’ function, and p-values were calculated using the ‘eBayes’ function. A trended and robust empirical Bayes analysis was performed. False discovery rates were estimated as q-values (Storey, 2002). Each comparison was tested for any difference from zero log2 fold change. Significant differentially expressed proteins were defined as those with q-values less than 0.05.
Volcano plots of differentially expressed proteins across all groups are shown in Figure 3, with a threshold of q-value < 0.05 and no log fold-change threshold. Full details of all proteins are provided in the supplementary results table DA_results_proteomics.xlsx within the Publication_tables folder.
The number of significant differentially expressed proteins is summarised in Figure 2 (q-value < 0.05). For the comparison KO_vs_WT, there were 9 upregulated and 10 downregulated proteins.
