# KIT-044: the state owner on every platform, one capability fallback for the GNU tools

Status 2026-10-26: **in progress**. Base build `kit_056` = `core/browser-smoke.qITMLl`.

## Mechanism (one)

`workflowToolPath(name)` memoises the lookup of `bash`, `dd`, `sha256sum`, `sync`, `tar` and `cp` (by `--version` banner for the coreutils and GNU tar); `MULTISCHOLAR_DISABLE_TOOLS` hides tools for tests and recorded runs. Where the tools are present every path is unchanged (the Linux behaviour of KIT-036 onward, byte for byte); where one is absent an R fallback runs under a contract the owner records on its context at creation (`workflowCapabilityContracts()`):

| Contract | With the tools | Fallback |
|---|---|---|
| `value_hash_mode` | `gnu_stream`: one serialised column streamed through `dd \| sha256sum` | `in_memory`: `digest(serializeVersion = 2)` of the same bytes (the same hex; the serialised column resident, measured below) |
| `file_hash_mode` | `gnu_stream` over 4 MiB | `digest_file`: `digest(file =)` for every size (the same hex) |
| `durability` | `fsync` by GNU `sync` on the owned paths | `not guaranteed`: the flush is a no-op after the same path validation (R has no fsync on a path) |
| `archive_format` | `gnu_pax`: GNU tar through `dd oflag=dsync,nocache` | `ustar_internal`: `utils::tar(tar = "internal")` from one staging directory of copies; `utils::untar(tar = "internal")`; the archive's entries read from its headers in R (regular files only, as the GNU listing path refuses anything else); the manifest's member hashes are the contract, the archive bytes differ by construction |
| `snapshot_copy` | `cp_reflink` | `file_copy` (`file.copy`, never overwriting; the same identity checks) |
| `cache_release` | `dd_nocache` | `none` (advice only) |

The two attach/ingest gates test `workflowOwnerCapable()` (qs2, DuckDB and Arrow present) instead of the platform. Unchanged: the systemd/cgroup paths (managed execution) and the P14 native rollup gate (x86_64 Linux; KIT-048 states the limit; KIT-051/052 decide the port).
