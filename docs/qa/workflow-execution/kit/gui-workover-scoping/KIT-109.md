### 3.3 How the closure proves there are no new silent skips

1. **Baseline:** KIT-101's full suite, recorded per file (pass, fail, error, skip), one process per file. This is the acceptance criterion's skip-count baseline.
2. **Closure, per file:** the full suite again. For every file:
   - Δskip must equal the number of quarantine skips executed in it, counted statically from the `skip("quarantined: Q-2[3-9]|Q-30` lines; a line-1 skip counts 1.
   - Δpass must be explained by those quarantines or by new entry-point tests.
