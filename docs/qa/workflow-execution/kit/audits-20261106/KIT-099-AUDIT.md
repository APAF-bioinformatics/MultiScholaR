## Verdict per dimension

1. **Completeness: not ready to execute; acceptable as a gated stub.** The deferral is explicit and gated. But nothing yet requires the stepped trial itself to be declared before it runs (F01, the A-11 recurrence), and there is no ledger row, no user go and no governing protocol for transcriptomics operation members (F02). Terminal outcomes for limit stops (F04), the large oracles (F12) and the hand-off contents for KIT-088 (F10) are missing. KIT-088's needs: sizes per size label in both dimensions and cells, corpus identities, the trial record, and the single-build curve stated.
2. **Scientific rigor: should-fix.** "Large/ultra" are undefined. A cells-only axis hides the grid's super-linear cost in samples (F03). The filter's pre-pass is TMM-effective library size, not library size (F07). The ceiling question presupposes RUV or edgeR (F08). Not-finishing semantics and the ≤ 1.02 / ≤ 0.95 rules aren't bound (F04, F06), and the TRX claim limits aren't carried over (F11).
3. **Implementation best practice: should-fix.** The ticket joins a measurement with a default change against the KIT-084/089 split (F05). The lifecycle item doesn't require forced failure or an operation-member small test (F09). Reuse of the KIT-084 pair harness is implied but not named, and `stage_084` needs a small generalisation (F16).
4. **Codebase reference accuracy: mostly accurate; minor.** Every cited path exists. The notebook is 793 lines (792 newlines, no trailing newline). `R CMD check` at 3 WARNINGs and 3 NOTEs matches recent outcomes, and `kitOperationDecision`, `single_084`, the 1,800 s deadline and the 16 GiB cap are where the neighbours say. Defects: the defaults file and missing test file (F13), the index title (F14), stale plan dependency rows (F15), and `ops.sh` unverifiable in the repo (F16).
