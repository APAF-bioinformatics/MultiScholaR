The data contains label-free quantification (LFQ) values for identified proteins across all samples. LFQ-based quantification provides relative abundance measurements through intensity-based algorithms (such as MaxLFQ for FragPipe or LFQ intensities for MaxQuant), which normalize protein abundances across samples without the use of isobaric tags. For FragPipe workflows, the MaxLFQ algorithm provides protein-level quantification by normalizing peptide intensities across samples. For MaxQuant workflows, LFQ intensities are calculated from peptide-level data and provide normalized protein abundances across all samples. Protein Quality Control and Filtering Protein identifications were filtered to ensure high-confidence quantification and reliable downstream statistical analysis. FASTA Reference and Protein Accession Cleanup Protein identifications were validated against the provided FASTA reference database to ensure accurate annotation. Protein accessions were cleaned and validated to ensure accurate annotation and to select the best representative protein ID when multiple accessions were present. Duplicate protein entries were removed to prevent redundancy in quantification. Proteins were then filtered based on missing value patterns across experimental groups to retain only those with sufficient coverage for robust statistical testing. Proteins were excluded if they had 33.333% or more missing values or values below the 2st percentile of intensity values within any individual experimental group. Additionally, proteins were required to pass this threshold in all experimental groups, ensuring comprehensive coverage across all conditions. Additionally, proteins with intensity values below the 2st percentile across all samples were excluded from further analysis as likely noise or background signal. Proteins appearing in only one replicate across all groups were also excluded to ensure measurement reproducibility and reliable quantification across biological replicates. Normalization and Batch Effect Correction Using the protein intensity matrix, zero values were replaced with NA to denote missing values. The data matrix was log (base 2) transformed and between-sample normalization was performed using the ‘cyclicloess’ method from the ‘limma’ R package (Ritchie et al., 2015). This normalization approach adjusts for systematic technical variation while preserving biological differences. RUV-III batch correction was not applied due to dataset constraints. The analysis proceeded directly with normalized data for differential abundance analysis. At each stage of the data normalization, the samples were checked for batch effects using principal component analysis (PCA) plots, density boxplots, relative log-expression (RLE) plots, and the distribution of Pearson correlation between replicate samples within groups.
