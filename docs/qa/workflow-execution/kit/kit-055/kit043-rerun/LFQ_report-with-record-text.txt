SOP reference: [to be completed by the analyst]. Data Import and Protein Quantification Protein-group quantification was imported from the MaxQuant proteinGroups export. The LFQ intensity columns were used: MaxQuant’s label-free quantification normalises peptide intensities across samples and reports one LFQ intensity per protein group and sample; a zero LFQ intensity denotes a missing value. Rows flagged as potential contaminants or reverse (decoy) hits were removed at import. Protein Quality Control and Filtering Protein identifications were filtered to ensure high-confidence quantification and reliable downstream statistical analysis. FASTA Reference and Protein Accession Cleanup Protein identifications were validated against the provided FASTA reference database to ensure accurate annotation. Protein accessions were cleaned and validated to ensure accurate annotation and to select the best representative protein ID when multiple accessions were present. Duplicate protein entries were removed to prevent redundancy in quantification. Proteins were then filtered on missing values within experimental groups. Intensities below the 2nd percentile of all intensities in the table were treated as missing. Within each group a protein failed if 33.333% or more of its values were missing; a protein was retained only if it passed in every experimental group. Proteins appearing in only one replicate across all groups were also excluded to ensure measurement reproducibility and reliable quantification across biological replicates. Normalization and Batch Effect Correction Using the protein intensity matrix, zero values were replaced with NA to denote missing values. The data matrix was log (base 2) transformed and between-sample normalization was performed using the ‘cyclicloess’ method from the ‘limma’ R package (Ritchie et al., 2015). This normalization approach adjusts for systematic technical variation while preserving biological differences. RUV-III batch correction was not applied due to dataset constraints. The analysis proceeded directly with normalized data for differential abundance analysis. At each stage of the data normalization, the samples were checked for batch effects using principal component analysis (PCA) plots, density boxplots, relative log-expression (RLE) plots, and the distribution of Pearson correlation between replicate samples within groups. These quality control visualizations allow assessment of technical variation removal while ensuring biological signal is retained. Differential Abundance Analysis DIFFERENTIAL ABUNDANCE ANALYSIS Differential abundance analysis of proteins was performed using the adjusted abundance matrix for the comparisons defined in the contrast table. The ‘limma’ R package (Ritchie et al., 2015) was used. A linear model was fitted using the formula ‘~ 0 + group’ with the ‘lmFit’ function, and p-values were calculated using the ‘eBayes’ function. A trended and robust empirical Bayes analysis was performed. The false discovery rate correction was applied to the moderated p-values by calculating the q-values (Storey, 2002). The standard empirical Bayes method was used to test for any deviation from zero log-fold-change. Significant differentially expressed proteins were defined as those with q-values less than 0.1. Volcano plots of differentially expressed proteins across all groups are shown in Figure 3, with a threshold of q-value &lt; 0.1 and no log fold-change threshold.
