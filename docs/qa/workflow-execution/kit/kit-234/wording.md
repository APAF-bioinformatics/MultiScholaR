## project_setup.R, left in place

`project_setup.R` is not edited and not archived until the owner answers OD-1 item 9. It downloads each workbook
from `https://raw.githubusercontent.com/APAF-bioinformatics/MultiScholaR/main/inst/workbooks/<omic>/<file>`
(`getWorkflowUrl()`, `project_setup.R:231-269`). `main` still holds `inst/workbooks/` today (`git ls-tree origin/main`,
2026-11-25), so the script works as before until this change reaches `main`. After that, a user who runs it sees, per
omic chosen, the warning

> Failed to download DIA_workflow_starter.rmd for proteomics. Status code: 404. URL: https://raw.githubusercontent.com/APAF-bioinformatics/MultiScholaR/main/inst/workbooks/proteomics/DIA_workflow_starter.rmd

(from `project_setup.R:479-480`; the file name and omic follow the choices), while the report template
(`inst/reports/...`), the central `config.ini` and the optional tutorial data still download, the folders are still
made, and the script ends with "Project setup complete!" without the "Workflow file (first omic): ..." line
(`project_setup.R:488-494`). README no longer links to the script (row 5); its old download URL keeps working.
