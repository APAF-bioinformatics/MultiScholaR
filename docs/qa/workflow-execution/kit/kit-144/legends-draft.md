# KIT-144: draft legends for the supplementary figures and tables (revised 2026-11-18; S1 and the decision-rule table added)

Drafts, plain and factual, for the author to rewrite. Every figure is written by `figures.R` from `kit-124/scored/`; Figures S6 and S7 also read `data/k124-main-runs.tsv.xz`, the per-data-set results of the main scenarios (written by `extract-runs.R`, which checks them against the scored tables). Numbers quoted below are read from `out/tableS-per-scenario-results.csv` or, for S6 and S7, from that per-data-set table. Figure S1 (two parts) is drawn from `definitions-source.psv` and holds no result. Figure S9 is not drawn yet (see the ticket). Draft text for the Methods and Results is in `methods-draft.md`.

## Shared definitions (once, in the first legend or the Methods)

- **Omics (simulators).** Proteomics, classic (S1); proteomics, DIA with limpa (S2; run on the `fastlimpadpc` engine); transcriptomics (S3); lipidomics and metabolomics (S4; one false discovery proportion per run over both assays).
- **Main scenarios.** Centre: 6 samples per group, 20% of features changed, one unwanted factor uncorrelated with the groups, 25% missing values where the omic has them, two groups. Each other main scenario moves one setting: 12 per group; 10% of features changed; no unwanted factor; no true effects (global null); factor correlated with the groups (ρ = 0.3); technical duplicates (4 units per group, 2 injections each); three groups. 1,000 simulated data sets per scenario and design.
- **Extra-hard scenarios.** 500 data sets each; they give conditions of use and were never used to judge a design.
- **Designs** (arm numbers of KIT-124 in brackets, for traceability; not on the figures). No RUV [1]. True factor known, the ceiling [2] (lipidomics/metabolomics: the true drift subtracted and the factor in the model). All features as controls, groups as replicate sets, factors in the model, k estimated [7]; the same with k = 1 [11]. Technical replicates as the replicate structure, all features as controls: factors in the model [16], corrected data tested [15]. Known null controls (50 true nulls, standing for a supplied list; internal standards in lipidomics/metabolomics), factors in the model [8]; the same, corrected data tested [10]; a control list in which 20% are true effects [9]. First-pass nulls: controls outside the 25% most significant features of a first test [5] (transcriptomics: RUVg) or with first-pass q > 0.5 [6], factors in the model. Legacy design [3]: controls are the least significant 5 to 30% of features and k is chosen by the separation rule; the test is on the corrected data in classic proteomics and lipidomics/metabolomics, is DIA's correction mode, and has the factors in the model in transcriptomics. Legacy controls and k with the factors in the model [4] (DIA: the covariates mode; transcriptomics: identical to the legacy design, not run separately). Other methods: RUV-4 [12] and RUVinv [13] with the known nulls, surrogate variable analysis [14] (transcriptomics: svaseq, and svaseq with the k of the RUV designs [14E]), RUVr [R], pooled QC injections as the replicate set [Qs corrected data tested, Qm factors in the model], internal-standard normalisation only [I], QC-based LOESS drift correction [L], the known batch in the model [17, known-batch scenario only].
- **Colours.** One colour per design in every figure (Okabe-Ito): grey no RUV, black ceiling, green all features as controls, sky blue technical replicates, blue known null controls, orange first-pass nulls, vermillion legacy; a lighter tint is the variant of the same family; purple other methods; mid grey other designs.
- **Reference lines.** Solid: the nominal level, 0.05. Dashed: the limit of the pre-specified decision rule, 0.075 (rule 1 for the type I error rate, rule 2 for the mean false discovery proportion).
- **Not judged (dagger, cross or faded).** Scenarios in which the ceiling design itself failed rule 1 or 2, so that no design was judged there: technical duplicates in transcriptomics and in lipidomics/metabolomics (the package fits technical replicates as independent samples in these omics), and the global null in lipidomics/metabolomics (an effect of scoring both assays as one family).
- **Numbers on axes and in cells** are written without the leading zero (.05 = 0.05).
- **Subset.** Each design is shown on its primary feature set: all features, or the features complete in every sample for RUV-4, RUVinv and surrogate variable analysis in classic proteomics and lipidomics/metabolomics.

## Figure S1. Design of the simulation study (two parts)

Files: `figS1a-study-design-scenarios` and `figS1b-study-design-designs-and-rules`. One page could not hold the four blocks legibly at 7 in wide (together they are 13.4 in high), so the schematic is split: (a) what was simulated, (b) what was compared and how it was judged.

**(a) Simulators and scenarios.** Top: the four simulators, one per analysis route of the package: what each generates, the analysis it runs, and the settings of its own centre scenario that differ from the common centre. Bottom: the scenarios as a grid, settings in rows and scenarios in columns. The first column gives every setting of the centre scenario. Each other column is filled only where that scenario departs from the centre, with the new value where it is short and a dot where the scenario table has to be read (technical duplicates: 2 injections or libraries per unit; heavy-tailed noise; loadings tied to abundance). Dark cells: the seven main scenarios, each changing one setting (the technical-duplicate scenario also has 4 units per group, so that it has 16 samples); 1,000 simulated data sets per scenario and design. Light cells: the 14 extra-hard scenarios, a second tier that states conditions of use and never fails a design; 500 data sets each. Shares and correlations are written without the leading zero. Transcriptomics has no missing values: its "no missing values" scenario is a low-count scenario and "50% missing" was not run there (scenario table).

**(b) Designs and decision rules.** Top: the RUV designs as a grid of the four choices they vary: negative controls, replicate sets, the rule for the number of unwanted factors (k) and what the test reads. One row per design that is not specific to one omic, in the order and colour of every other figure, under its tier of the option set; a filled point marks the option the design takes in every omic that ran it, a ring an option it takes in some omics only (known-null and first-pass-null designs use no replicate sets in transcriptomics, where they are RUVg; the legacy design tests the corrected data except in transcriptomics, where the factors are in the model). Below the grid: the two reference designs and the designs and methods that are not rows of the grid. Bottom: the seven decision rules with their limits, the rule for bounds, for void scenarios and for the verdict, as declared before the confirming runs, with the declaration's working terms replaced by the terms of the figures (the declared wording is in the decision-rule table).

## Figure S2. Calibration of every design in every main scenario (two parts)

Files: `figS2-calibration-heatmap-part1` (proteomics, classic; proteomics, DIA) and `-part2` (transcriptomics; lipidomics and metabolomics).

Mean false discovery proportion among the features called at q < 0.05 (nominal 0.05), for each design (rows) in each main scenario (columns), one panel per omic; 1,000 simulated data sets per cell. The value is written in each cell. Each panel lists the designs that were run in that omic, in the same order everywhere; the coloured square beside a design is its colour in the other figures. Colour of the cells is the ratio to the nominal level on a log scale: white at 0.05, blue below (conservative), red above (liberal), clipped at 0.0125 and 0.8. Empty cells: the design was not run in that scenario (designs with technical replicates were run in the technical-duplicate scenario only; the contaminated control list was not run under the global null in the two proteomics simulators). † scenario not judged (see shared definitions). In the global-null scenario the false discovery proportion of a data set is 1 if any feature is called, so the mean equals the share of data sets with any call.

## Figure S3. Type I error rate per design and omic

Share of true null features with p < 0.05 for each design (rows) and omic (panels); one point per main scenario, in the order of Figure S2 from top to bottom within a row, with mean ± 1.96 Monte Carlo standard errors over 1,000 data sets (most intervals are narrower than the point). Filled circle: centre scenario; triangle: unwanted factor tied to the groups (ρ = 0.3); open circles: the other main scenarios; crosses: scenarios not judged. Solid line: nominal 0.05; dashed line: the rule-1 limit, 0.075. Square-root axis.

## Figure S4. False discoveries against power

Mean false discovery proportion against power, one row of panels per omic and one column per design of the option set and the two references. In each panel the design named above it is the filled, coloured point (centre scenario; mean ± 1.96 Monte Carlo standard errors in both directions, 1,000 data sets, mostly narrower than the point). The open point of the same colour joined to it is the same design in the judged main scenario with true effects where its mean false discovery proportion is highest, set at the centre scenario's power. The black ring is the ceiling (true factor known) in the centre scenario: a design inside the ring matches the ceiling. Small grey points: every other design and method in the centre scenario (identified in the results table). Shaded: the calibrated region, mean false discovery proportion at most 0.075 (rule 2, dashed line); solid line: nominal 0.05. Designs with technical replicates are not shown (they were run in the technical-duplicate scenario only; Figures S2 and S3). Square-root vertical axis; the same axes in every panel.

## Figure S5. One choice changed at a time

Mean false discovery proportion (± 1.96 Monte Carlo standard errors; 1,000 data sets) in each main scenario for two pairs of designs that differ in one choice. Top, the test form: known null controls and the same k, with the factors in the model (filled) or with the test run on the corrected data (open) [arms 8 and 10]. Bottom, the control set: factors in the model in both, with all features as controls (filled) or with the legacy control set, the least significant 5 to 30% of features (open) [arms 7 and 4]; the two also differ in how k is chosen (estimated count against the separation rule), which goes with the control set. In transcriptomics the legacy design already has the factors in the model, so the legacy design itself is drawn as the open marker [arm 3]. Faded: scenarios not judged. ## Figure S6. Distribution of the false discovery proportion over the simulated data sets

File: `figS6-fdp-distribution`.

False discovery proportion of each simulated data set (false calls among the features called at q < 0.05; 0 when nothing is called), summarised over the 1,000 data sets of each main scenario (rows), for the designs of the option set and the two references (blocks, each in its colour) in each omic (columns). Thick bar: 25th to 75th percentile; medium bar: 5th to 95th; thin line: 1st to 99th; vertical tick: median; diamond: mean, the value shown in Figure S2. Solid line: nominal 0.05; dotted line: 0.10. The number at the right of each panel is the share of data sets with a false discovery proportion above 0.10 (the quantity of rule 3). In the global-null scenario the proportion of a data set is 0 or 1, so an interval reaches 1 as soon as the share of data sets with any call exceeds its upper percentile, and the number at the right equals the mean. Lipidomics/metabolomics: one proportion per data set over both assays. Faded: scenarios not judged. Designs with technical replicates are not shown (run in the technical-duplicate scenario only). Square-root axis, the same in every panel.

Values for the text (centre scenario; classic proteomics, DIA, transcriptomics, lipidomics/metabolomics). All features as controls: 99th percentile 0.107, 0.095, 0.065, 0.180; share above 0.10: 0.025, 0.003, 0.000, 0.164. Ceiling: 99th percentile 0.102, 0.092, 0.065, 0.163; share above 0.10: 0.013, 0.001, 0.000, 0.134. Over the judged main scenarios with true effects, the share above 0.10 for all features as controls is 0.153 to 0.278 in lipidomics/metabolomics (ceiling 0.075 to 0.255), where 7 to 51% of data sets have a proportion of exactly 0; in classic proteomics it is highest at 12 per group, 0.115 (ceiling 0.007). Legacy design, centre scenario: median 0.093, 0.279, 0.046, 0.486.

## Figure S7. Number of unwanted factors: estimated against true

File: `figS7-factors-estimated-against-true`.

Number of unwanted factors removed (k) under the two rules, as they were run: left, the estimated count (`sva::num.sv`, permutation method, 20 permutations) in the design with all features as controls (one estimate per data set, shared by every design that uses it); right, the separation rule in the legacy design. Each cell is the share of the 1,000 data sets of a main scenario (columns) in which k took the value of the row; shares under 0.005 are written <.01 and cells without a data set are empty. Outlined: the true number of unwanted factors of the scenario (1; 0 in the scenario without an unwanted factor; 2 in lipidomics/metabolomics, drift along injection order and one sample-wise factor). In lipidomics/metabolomics k is the mean over the two assays, hence the half steps. Values of 5 or more share one row. † scenario not judged in the other figures (the count of factors does not depend on the test). The first-pass-null designs take the legacy design's k in the two proteomics routes and in transcriptomics; in lipidomics/metabolomics they apply the separation rule to their own controls (mean k in the results table).

Values for the text. Where a factor exists the estimated count equals the true number in 99.4 to 100% of data sets in the two proteomics routes and in transcriptomics, and in 92.7 to 99.9% in lipidomics/metabolomics; it exceeds it in under 1% of data sets in the proteomics routes and in none elsewhere. Without an unwanted factor it returns 0 in 88.9% (classic proteomics), 86.7% (DIA), 36.2% (transcriptomics) and 77.2% (lipidomics/metabolomics) of data sets. The separation rule returns more than the true number in 21.7 to 100% of data sets, depending on omic and scenario, and never returns 0.

## Table S (per-scenario results), `tableS-per-scenario-results.csv`

One row per omic, scenario, design and feature subset (`primary` marks the subset shown in the figures). Columns: identifiers (`omic`, `simulator`, `scenario_class`, `cell`, `scenario`, `design`, `tier`, `arm`, `subset`, `primary`, `state` final or partial, `not_judged`, source `folder`); counts (`runs`, `scored`, designed and method refusals, crashes; a refused run carries its data set's no-RUV result); `mean_k`, the mean number of factors removed; the type I error rate at 0.05 (`null05`) and 0.01 (`null01`), the mean false discovery proportion (`mean_fdp`), power, bias and root mean square error of the log2 differences of true effects, each with its Monte Carlo standard error and, where given, mean ± 1.96 standard errors (`_lower`, `_upper`); the share of data sets with a false discovery proportion above 0.10 (`fdp10_share`) and with any call (`anycall_share`) with exact one-sided 97.5% bounds; the status of each decision rule (`rule1` to `rule7`), rule 3's limit and the row's verdict, as scored by `kit-124/aggregate.R`.

## Table S (design definitions), `tableS-design-definitions.csv`

One row per omic and design run there: the design's name and tier as on the figures, its KIT-124 arm number, its negative controls, replicate sets, the rule for the number of factors, what the test reads, and the scenarios in which it was scored (KIT-124 cell codes; extra-hard scenarios as far as they are scored).

## Table S (scenario definitions), `tableS-scenario-definitions.csv`

One row per omic and scenario (8 main, 14 extra-hard): number of groups, biological units per group, technical replicates, share of features with a true effect and the share of those that are up, the true number of unwanted factors, the factor's correlation with the groups, the share of missing values, the noise distribution, a note where the simulator realises the setting in its own way, and `not_run` where a scenario has no counterpart in an omic.

## Table S (simulator parameters), `tableS-simulator-parameters.csv`

One row per omic and parameter of its simulator (features, abundance and variance model, size of the true effects, the unwanted factor and its strength, missing values, the test and the calling rule, the unit of the false discovery proportion, the two rules for the number of factors, seeds, numbers of data sets), with the file that states it, and the software versions each simulator recorded.

## Table S (decision rules), `tableS-decision-rules.csv`

One row per decision rule (1 to 7) and one each for the bounds, void scenarios and the verdict of a design. Columns: the rule and its limit as declared before the confirming runs (quoted; "arm" is the declaration's word for a design, "cell" for a scenario, "run" for a simulated data set, "core" and "stress" for main and extra-hard); the measure as declared; the scenarios and designs it applies to; the source the declaration states for it, or that it states none; the readings taken and the amendments made when the rules were applied, each with its label in the scoring script (A1 to A14); and where the declaration is written.

All four are written by `figures.R` from `definitions-source.psv` (one row per definition, with its source; the figures' true number of factors is read from the same file) and, for versions and the scenarios scored, from `kit-124/scored/`.
