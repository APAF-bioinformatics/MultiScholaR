# KIT-144: draft legends for the supplementary figures and table (pass 1, revised 2026-11-18)

Drafts, plain and factual, for the author to rewrite. Every figure is written by `figures.R` from `kit-124/scored/`; numbers quoted below are read from `out/tableS-per-scenario-results.csv`. Figures S1, S6, S7 and S9 are not drawn yet (see the ticket).

## Shared definitions (once, in the first legend or the Methods)

- **Omics (simulators).** Proteomics, classic (S1); proteomics, DIA with limpa (S2; run on the `fastlimpadpc` engine); transcriptomics (S3); lipidomics and metabolomics (S4; one false discovery proportion per run over both assays).
- **Main scenarios.** Centre: 6 samples per group, 20% of features changed, one unwanted factor uncorrelated with the groups, 25% missing values where the omic has them, two groups. Each other main scenario moves one setting: 12 per group; 10% of features changed; no unwanted factor; no true effects (global null); factor correlated with the groups (ρ = 0.3); technical duplicates (4 units per group, 2 injections each); three groups. 1,000 simulated data sets per scenario and design.
- **Extra-hard scenarios.** 500 data sets each; they give conditions of use and were never used to judge a design.
- **Designs** (arm numbers of KIT-124 in brackets, for traceability; not on the figures). No RUV [1]. True factor known, the ceiling [2] (lipidomics/metabolomics: the true drift subtracted and the factor in the model). All features as controls, groups as replicate sets, factors in the model, k estimated [7]; the same with k = 1 [11]. Technical replicates as the replicate structure, all features as controls: factors in the model [16], corrected data tested [15]. Known null controls (50 true nulls, standing for a supplied list; internal standards in lipidomics/metabolomics), factors in the model [8]; the same, corrected data tested [10]; a control list in which 20% are true effects [9]. First-pass nulls: controls outside the 25% most significant features of a first test [5] (transcriptomics: RUVg) or with first-pass q > 0.5 [6], factors in the model. Legacy design [3]: controls are the least significant 5 to 30% of features and k is chosen by the separation rule; the test is on the corrected data in classic proteomics and lipidomics/metabolomics, is DIA's correction mode, and has the factors in the model in transcriptomics. Legacy controls and k with the factors in the model [4] (DIA: the covariates mode; transcriptomics: identical to the legacy design, not run separately). Other methods: RUV-4 [12] and RUVinv [13] with the known nulls, surrogate variable analysis [14] (transcriptomics: svaseq, and svaseq with the k of the RUV designs [14E]), RUVr [R], pooled QC injections as the replicate set [Qs corrected data tested, Qm factors in the model], internal-standard normalisation only [I], QC-based LOESS drift correction [L], the known batch in the model [17, known-batch scenario only].
- **Colours.** One colour per design in every figure (Okabe-Ito): grey no RUV, black ceiling, green all features as controls, sky blue technical replicates, blue known null controls, orange first-pass nulls, vermillion legacy; a lighter tint is the variant of the same family; purple other methods; mid grey other designs.
- **Reference lines.** Solid: the nominal level, 0.05. Dashed: the limit of the pre-specified decision rule, 0.075 (rule 1 for the type I error rate, rule 2 for the mean false discovery proportion).
- **Not judged (dagger, cross or faded).** Scenarios in which the ceiling design itself failed rule 1 or 2, so that no design was judged there: technical duplicates in transcriptomics and in lipidomics/metabolomics (the package fits technical replicates as independent samples in these omics), and the global null in lipidomics/metabolomics (an effect of scoring both assays as one family).
- **Numbers on axes and in cells** are written without the leading zero (.05 = 0.05).
- **Subset.** Each design is shown on its primary feature set: all features, or the features complete in every sample for RUV-4, RUVinv and surrogate variable analysis in classic proteomics and lipidomics/metabolomics.

## Figure S2. Calibration of every design in every main scenario (two parts)

Files: `figS2-calibration-heatmap-part1` (proteomics, classic; proteomics, DIA) and `-part2` (transcriptomics; lipidomics and metabolomics).

Mean false discovery proportion among the features called at q < 0.05 (nominal 0.05), for each design (rows) in each main scenario (columns), one panel per omic; 1,000 simulated data sets per cell. The value is written in each cell. Each panel lists the designs that were run in that omic, in the same order everywhere; the coloured square beside a design is its colour in the other figures. Colour of the cells is the ratio to the nominal level on a log scale: white at 0.05, blue below (conservative), red above (liberal), clipped at 0.0125 and 0.8. Empty cells: the design was not run in that scenario (designs with technical replicates were run in the technical-duplicate scenario only; the contaminated control list was not run under the global null in the two proteomics simulators). † scenario not judged (see shared definitions). In the global-null scenario the false discovery proportion of a data set is 1 if any feature is called, so the mean equals the share of data sets with any call.

## Figure S3. Type I error rate per design and omic

Share of true null features with p < 0.05 for each design (rows) and omic (panels); one point per main scenario, in the order of Figure S2 from top to bottom within a row, with mean ± 1.96 Monte Carlo standard errors over 1,000 data sets (most intervals are narrower than the point). Filled circle: centre scenario; triangle: unwanted factor tied to the groups (ρ = 0.3); open circles: the other main scenarios; crosses: scenarios not judged. Solid line: nominal 0.05; dashed line: the rule-1 limit, 0.075. Square-root axis.

## Figure S4. False discoveries against power

Mean false discovery proportion against power, one row of panels per omic and one column per design of the option set and the two references. In each panel the design named above it is the filled, coloured point (centre scenario; mean ± 1.96 Monte Carlo standard errors in both directions, 1,000 data sets, mostly narrower than the point). The open point of the same colour joined to it is the same design in the judged main scenario with true effects where its mean false discovery proportion is highest, set at the centre scenario's power. The black ring is the ceiling (true factor known) in the centre scenario: a design inside the ring matches the ceiling. Small grey points: every other design and method in the centre scenario (identified in the results table). Shaded: the calibrated region, mean false discovery proportion at most 0.075 (rule 2, dashed line); solid line: nominal 0.05. Designs with technical replicates are not shown (they were run in the technical-duplicate scenario only; Figures S2 and S3). Square-root vertical axis; the same axes in every panel.

## Figure S5. One choice changed at a time

Mean false discovery proportion (± 1.96 Monte Carlo standard errors; 1,000 data sets) in each main scenario for two pairs of designs that differ in one choice. Top, the test form: known null controls and the same k, with the factors in the model (filled) or with the test run on the corrected data (open) [arms 8 and 10]. Bottom, the control set: factors in the model in both, with all features as controls (filled) or with the legacy control set, the least significant 5 to 30% of features (open) [arms 7 and 4]; the two also differ in how k is chosen (estimated count against the separation rule), which goes with the control set. In transcriptomics the legacy design already has the factors in the model, so the legacy design itself is drawn as the open marker [arm 3]. Faded: scenarios not judged. Solid line: nominal 0.05; dashed line: the rule-2 limit, 0.075. Square-root axis, the same in every panel.

## Figure S8. Extra-hard scenarios (a: false discoveries; b: power), PARTIAL

**State: partial.** Drawn from `s34-stress-partial` (transcriptomics and lipidomics/metabolomics only, scored 2026-11-18); each file carries a line "PARTIAL: ..." above the panel until the final scoring of all four omics is committed, when a re-run removes it. The scenario list below is to be revised then. Files: `figS8a-extra-hard-fdp-part1` and `figS8b-extra-hard-power-part1` (transcriptomics), `-part2` (lipidomics and metabolomics); one omic per file, since two do not fit a page.

(a) Mean false discovery proportion and (b) power of each design (rows) in each extra-hard scenario (columns); 500 simulated data sets per cell; rows and colour in (a) as in Figure S2. Scenarios: 3 per group; 40% of features changed; factor strongly tied to the groups (ρ = 0.6); three unwanted factors; no missing values (transcriptomics: low counts, library size divided by 10); 50% missing; heavy-tailed noise (t, 4 degrees of freedom); a known, unbalanced batch; 80% of effects in one direction; loadings tied to abundance; 3 per group with the factor tied to the groups. † scenario in which the ceiling design was itself miscalibrated. Extra-hard scenarios were not used to judge designs; they state where a design stops holding.

## Table S (per-scenario results), `tableS-per-scenario-results.csv`

One row per omic, scenario, design and feature subset (`primary` marks the subset shown in the figures). Columns: identifiers (`omic`, `simulator`, `scenario_class`, `cell`, `scenario`, `design`, `tier`, `arm`, `subset`, `primary`, `state` final or partial, `not_judged`, source `folder`); counts (`runs`, `scored`, designed and method refusals, crashes; a refused run carries its data set's no-RUV result); `mean_k`, the mean number of factors removed; the type I error rate at 0.05 (`null05`) and 0.01 (`null01`), the mean false discovery proportion (`mean_fdp`), power, bias and root mean square error of the log2 differences of true effects, each with its Monte Carlo standard error and, where given, mean ± 1.96 standard errors (`_lower`, `_upper`); the share of data sets with a false discovery proportion above 0.10 (`fdp10_share`) and with any call (`anycall_share`) with exact one-sided 97.5% bounds; the status of each decision rule (`rule1` to `rule7`), rule 3's limit and the row's verdict, as scored by `kit-124/aggregate.R`.
