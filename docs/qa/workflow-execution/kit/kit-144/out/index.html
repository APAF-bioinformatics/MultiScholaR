Which RUV designs can MultiScholaR offer, and which one should be the default?

Simulation study of unwanted-variation removal across four omics · results as scored on 18 November 2026 · main scenarios final, extra-hard scenarios partial

MultiScholaR removes unwanted variation (batch, run order, sample handling) with RUV before testing for differences between groups. We tested every way the package could do this on simulated data where the truth is known. One design holds its false discovery rate in every omic at almost no cost in power. The design the package uses today does not: at a nominal 5% it returned 30% to 56% false discoveries in its worst main scenario.

  • The recommended design matches the best possible result in three of four omics, and stays inside the limit in the fourth.
  • Today's design finds the same number of real differences but reports many false ones. It is worst when the unwanted factor partly follows the groups, and in DIA and lipidomics/metabolomics it is liberal in nearly every scenario.
  • Not correcting is not a safe fallback. It keeps the error rate in three omics only by finding almost nothing (power under 1% in transcriptomics and lipidomics/metabolomics when unwanted variation is present).

Why this was run

A review of the package found that its RUV step, although each computation matches the published software exactly, is used differently from the method papers in three ways. Each could plausibly inflate false discoveries, and code inspection cannot say by how much.

ChoiceToday's designMethod papers
Negative-control featuresThe least significant 5 to 30% of features from a first test, picked by a grid searchReplicate-based RUV: all features "works well in practice" (RUVSeq). Control-only RUV: keep most features, drop only the clearly changed ones
Number of unwanted factors (k)Chosen by the same grid searchNo fixed rule; judgment with diagnostics. RUVSeq's example uses 1
What the test readsClassic proteomics, lipidomics, metabolomics: the corrected dataRNA-seq and limma convention: uncorrected data with the unwanted factors in the model; corrected data "only for exploration"

The package will be described in a methods paper and shipped to users who will not check these choices themselves. The study was run to put a measured error rate beside every option the software offers, and to choose the default on evidence.

What was run

SimulatorsFour, one per analysis route: classic proteomics; DIA proteomics with limpa; transcriptomics (counts); lipidomics and metabolomics (two assays, internal standards, pooled QC injections). Each generates data with known true differences and a known unwanted factor, then runs the package's own code path.
Main scenariosEight per simulator. A centre scenario (6 samples per group, 20% of features changed, one unwanted factor unrelated to the groups), and seven that each change one setting: 12 per group; 10% changed; no unwanted factor; no true differences at all; unwanted factor partly following the groups (correlation 0.3); technical duplicates; three groups.
Size1,000 simulated data sets per scenario: 32,000 data sets in the main scenarios, each analysed by every design.
Designs comparedNo RUV; the true factor given to the model (the ceiling); today's design; and designs that change one choice at a time: the control set (all features, known true nulls, first-pass nulls, a contaminated list), the test form (factors in the model, or corrected data tested), the replicate structure (groups or technical replicates), and k (estimated or fixed at 1). Other published methods (RUV-4, RUVinv, surrogate variable analysis) were run for comparison.
MeasuresType I error rate (true nulls with p < 0.05); mean false discovery proportion among features called at q < 0.05; share of data sets with more than 10% false discoveries; power.
Decision rulesWritten down and independently reviewed before the confirming runs. A design passes when its type I error rate and mean false discovery proportion stay at or below 0.075 against a nominal 0.05 in every judged main scenario, and its power is not materially below the ceiling.
Extra-hard scenariosEleven per simulator at 500 data sets each (3 per group, 40% changed, strong confounding, three unwanted factors, 50% missing values, heavy-tailed noise and others). They state where a design stops holding and were not used to choose between designs. Two of four simulators have finished these.

How to read the figures

  • Solid line: the nominal level, 0.05. Dashed line: the limit of the decision rule, 0.075. Below the dashed line is calibrated.
  • Ceiling: the analysis with the true unwanted factor handed to the model. No real method can do better, so a design that matches it has nothing left to gain.
  • One colour per design in every figure: green recommended (all features as controls), vermillion legacy, orange first-pass nulls, blue known null controls, grey no RUV, black ceiling.
  • Axes for false discoveries use a square-root scale so that values near 0.05 are not squashed. Numbers are written without the leading zero (.05 = 0.05).
  • Faded points and daggers mark scenarios where even the ceiling failed, so no design was judged there.

What was decided from this

Every design stays available in every omic, because users have legitimate reasons to prefer one (existing results to reproduce, a trusted control list, technical replicates). Each option carries its measured error rate and its conditions of use in the interface, the saved record and the report's methods text. The recommended design is pre-selected.

TierOptionNote shown to the user
RecommendedGroups as replicate sets, all features as controls, unwanted factors in the modelPre-selected in all four omics
Valid with conditionsTechnical replicates as the replicate structureWhen technical replicates are declared
Valid with conditionsA supplied control list (housekeeping features, internal standards), factors in the modelA list that contains changing features inflates false discoveries
Valid with conditionsFirst-pass null controls (drop the most significant 25%), factors in the modelNot when the unwanted factor follows the groups; weaker in DIA and lipidomics/metabolomics
Legacy, warnedToday's design, unchangedReproduces earlier results; measured false discoveries 30% to 56% at a nominal 5%
NoneNo RUVLoses most power when unwanted variation is present; not calibrated in DIA

The corrected data are still computed under every option and used for PCA, plots, export and multi-omics integration. "Factors in the model" changes only what the statistical test reads.

The number of unwanted factors is estimated automatically by a permutation method (the one used in surrogate variable analysis), which returned the true number in the simulations (mean 1.00 where the truth was 1, 3.00 where it was 3). The package's existing rule, which reads a diagnostic plot, stays selectable wherever a separate control set exists, and the user can always set the number directly. Both rules come with a diagnostic plot.

Limits, and what is still to come

  • Simulation only. The data follow the models we wrote. A check on public real data, splitting samples from one group into two false groups so that no true difference exists, is planned and will be added as a further figure.
  • Technical replicates rest on thin evidence. That option was judged in one scenario in each proteomics route. In transcriptomics and lipidomics/metabolomics the technical-duplicate scenario was void: the package treated duplicates as independent samples there, so even the ceiling failed (27%). That defect has since been repaired and the scenario will be re-measured.
  • Lipidomics/metabolomics has no valid "no true differences" check. Both assays were scored as one family in that scenario, which voids it.
  • DIA was measured on one of the two quantification engines (the fast reimplementation). The result is expected, not measured, to carry over to the reference limpa engine.
  • Extra-hard scenarios are partial (Figure S8).
  • Three further designs are being simulated so that every selectable combination of control set and k rule has its own measured figure. They add rows to these figures; they do not change the ones shown.
  • Four planned supplementary figures are not drawn yet: the study design schematic, per-data-set distributions, estimated against true number of factors, and the real-data check.
