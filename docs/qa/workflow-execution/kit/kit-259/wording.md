  and does not list the replaced panels; only the panel says why. (a) accept, or (b) the report names the replaced
  panels (recommended before release; a later ticket). `outcome.md` section 7.

  (the same by default); after a 'Color by' change the figure used to choose the threshold shows other pairs than the
  filter tests (F10).

  while lipidomics and metabolomics now count them in a subtitle (F11; omics parity).

  (F9; by reading).
