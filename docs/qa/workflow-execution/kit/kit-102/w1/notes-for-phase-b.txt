Once W2 and W3 move them to the core, the lead adds import$preview and import$process (W2's core, or importOmicsTables; W3's importProteomicsData) and trx import$check = checkTrxImportCounts, moved to func_trx_counts.R. The lead then makes them required in omicGuiConfigSchema(). W2 and W3 do not edit R/utils_omic_gui_config.R; they report the function names to wire.

W2 rules:
- **Assay names:** the rules come from import$assay_names. Lipid and trx use 'require_pair', which checks before assembly. Metab uses 'skip_incomplete': a second assay counts only with both a file and a name, the path rule runs inside the validation, and the duplicate message ends in ': ' followed by the names.
- **Readers:** looked up by detected format with a 'default' fallback, for both the preview and the second assay. second_assay_columns decides whether the second assay's reader gets the id and annotation columns (lipid TRUE, metab FALSE).
- **Validation message:** refusal_prefix, then ': ', then the errors joined with '; '. Trx adds ' (trx_counts_invalid)' through its check plugin.

W4 rendering:
- **Headers:** lipid, metab and trx use h2(icon(header_icon), paste0(' ', label, ' Workflow'), style = 'margin-bottom: 20px;'). Proteomics has no header.
- **Tabs, 'icon_in_title' style:** tabPanel(title = tagList(icon(icon), title), value, div(`data-testid` = testid, ui)).
- **Tabs, 'icon_argument' style (proteomics):** tabPanel(title, value = value, icon = icon(icon), br(), div(...)).
- **Test id:** the outer tabset's is paste0(shell$testid, '-workflow-tabs').
- **Initial tab_status:** the first tab 'pending' and the rest 'disabled', in the bus's tab_status position. Lipid norm gets selected_tab.
- **Components:** resolved through omicGuiComponent(tab$component); for example 'trx_import' maps to mod_lipid_import_* with the trx profile.
- **Proteomics import success** sets design_matrix to 'pending' unconditionally (completeProtImportSuccessState, mod_prot_import_processing_helpers.R:375-378). Lipid sets it only when it is 'disabled' (:309-311). The frame's completion helper must keep each.
