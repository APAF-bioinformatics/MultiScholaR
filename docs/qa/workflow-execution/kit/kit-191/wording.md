| `enrich_test_permutation_note_genes_proteins` | Each feature's correlation with the factor is compared with what 1,000 random reorderings of the factor's values across the biological samples give, so features that vary together keep varying together (the permutation test of PCGSE, Frost et al. 2015). The reorderings stand for a factor that follows no feature; this factor was learned from these same data and follows the features it was learned from, which no reordering reproduces, so the test does not allow for that. It treats the biological samples as interchangeable, which samples taken in pairs, repeatedly from one subject, or in batches are not. In a check on simulated data with 12 biological samples, terms with no link were called at the 5 % level in 4.8 to 5.3 % of cases against values unrelated to the data, whatever the kind of term (the most variable features: 4.9 to 5.3 %), and in 0.4 to 4.4 % on the main factor; terms of 10 genes or proteins in which half the features truly followed the main factor were found in 39 to 52 % of cases (the default test: 60 to 62 %), of 30 in 80 to 96 % (in result tables of about 120 to 150 terms, about 1 in 6 truly linked). With 6 biological samples it found 0.2 to 3.2 % of such terms (10 to 100 features). On factors weaker than the main effect, terms of features the model used were called in up to 12.7 %. |

| `enrich_test_gsea_note_genes_proteins` | Every feature is ranked by its correlation with the factor, and a term is called when its features sit nearer the top or the bottom of the list than chance (GSEA). The test shuffles features as if each were independent. Features that vary together, such as the members of one pathway or one complex, make its p-values too small: in a check on simulated data with 12 biological samples, terms with no link to the factor whose features were correlated at 0.3 were called at the 5 % level in 40.2 to 43.0 % of cases (terms of 10 to 100 genes or proteins), against 5 % expected. The factor was learned from these same data. Use it to explore; it also uses features with missing values, whose correlations, computed on fewer samples, are noisier and sit more often near the ends of the list. In the same check, terms of 10 genes or proteins in which half the features truly followed the main factor were found in 63 to 72 % of cases, a figure that comes with the excess on correlated terms above (in result tables of about 120 to 150 terms, about 1 in 6 truly linked). |
| `enrich_test_gsea_note_metabolites` | Every feature is ranked by its correlation with the factor, and a term is called when its features sit nearer the top or the bottom of the list than chance (GSEA). ## The record and Methods (`R/utils_integration_record.R`)

| Key | Proposed wording |
|---|---|
| `col_enrich_score` | Enrichment score (NES), or effect: the difference in mean z-score (correlation-adjusted tests) or in mean Fisher-transformed correlation (permutation) between the term and the other features |
| `enrich_ranking_value_camera_floor` | regression of each feature on the factor over %d biological samples (features measured in all of them: %d); correlation-adjusted test, negative correlations counted as zero (camera, correlation estimated, allow.neg.cor = FALSE) |
| `enrich_ranking_value_permutation` | correlation of each feature with the factor over %d biological samples (features measured in all of them: %d); permutation test of the factor's values (PCGSE) |
| `methods_test_name_camera_floor` | a competitive gene-set test that allows for the correlation between a term's features, negative estimates counted as zero (limma camera with allow.neg.cor = FALSE; Wu and Smyth 2012), applied to the regression of each feature's values on the oriented factor |
| `methods_test_name_permutation` | a competitive gene-set test of each term's mean Fisher-transformed correlation with the oriented factor against the other features, its p-value from %d random reorderings of the factor's values across the biological samples (PCGSE's permutation test, Frost et al. 2015; p = (1 + b) / (1 + %d), reorderings that leave the factor unchanged counted) |
| `methods_test_settings_camera_floor` | the correlation estimated for each term (negative estimates counted as zero), moderated variances with an abundance trend, an intercept and no other covariate, features measured in every one of %d biological samples (%d of %d matched identifiers; several features on one identifier: the one with the largest mean value kept) |
| `methods_test_settings_permutation` | seed %d, the factor's values reordered with the model unchanged, features measured in every one of %d biological samples (%d of %d matched identifiers; several features on one identifier: the one with the largest mean value kept) |
| `methods_enrich_camera_floor` | %s in %s: %s pathways were tested with %s, %s, %s, organism %s, pathways with %d to %d of these identifiers (%d pathways), every pathway kept. |
| `methods_enrich_permutation` | %s in %s: %s pathways were tested with %s, %s, %s, organism %s, pathways with %d to %d of these identifiers (%d pathways), every pathway kept. |

| `methods_enrich_limits_clause` | the %s, on %s data, called terms with no link to the factor in %s of cases against values unrelated to the data, terms made only of the most variable features, those the model selects, in %s, and, on factors weaker than the main effect, terms of features the model used in up to %s |
| `methods_enrich_limits_end` | The correlation-adjusted and permutation tests use only features measured in every biological sample, which favours abundant features and leaves out features that fall below detection in some samples, often those that change most. The tests used read each data set's normalised values before RUV correction, the values the model is trained on by default; for a model trained on RUV-corrected values, variation the correction removed stays in the values tested. P-values were adjusted within each factor, data set and database (and Gene Ontology aspect), not across them. |
