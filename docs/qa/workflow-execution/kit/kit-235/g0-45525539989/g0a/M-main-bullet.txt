== method_details

• Brief summary of method(s):

Multi-Assay Data Structure
The dataset contains 2 assays: assay_pos, assay_neg. Each assay was processed independently through quality control and normalization steps before integration for differential abundance analysis.

Data Preprocessing and Normalization
Metabolite intensities were log2-transformed with an offset of 1 to stabilize variance. Missing values (zeros or non-detects) were coded as NA to distinguish
true absence from missing measurements.

ITSD Normalization
Internal standard (ITSD) normalization was applied using the median method with sum aggregation across ITSD features. Internal standard features were removed after normalization.

Between-sample normalization was performed using the 'PQN' method from
the 'limma' R package (Ritchie et al., 2015) to account for systematic technical
variation across samples.

Batch Effect Correction
To remove batch effects from biological data, the remove unwanted variation (RUVIII-C) method was used. The method relies on having a set of endogenous negative control metabolites, which are features with little or no changes in abundance between different samples. RUV correction was applied independently to each assay using the 'group' variable to preserve biological signal. For assay_pos, 2 unwanted components were removed using 1 empirical negative control metabolites. For assay_neg, 3 unwanted components were removed using 2 empirical negative control metabolites.

Quality Control
At each stage of data normalization, samples were checked for batch effects using:
• Principal component analysis (PCA) to visualize sample clustering
• Density boxplots to assess distribution consistency
• Relative log-expression (RLE) plots to detect systematic biases
• Pearson correlation matrices to evaluate replicate consistency

Per-Assay Quality Metrics
Quality control metrics were evaluated separately for each assay to ensure data
quality before integration. Each assay underwent independent QC assessment
following the same protocol, with cross-assay consistency verified in the
combined analysis.
