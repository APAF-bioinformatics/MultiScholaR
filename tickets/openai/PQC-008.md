# PQC-008: Emit a complete peptide-QC audit ledger and E2E evidence

## Description

Close the audit by making every transformation independently inspectable and
reproducible. Each applied stage must preserve its parent, state exactly what it
received and executed, distinguish frozen identification evidence from current
quantitative survivors, and identify every removed or imputed entity.

## Scientific Contract

- Every stage records parent/current state IDs, timestamp, implementation
  version, resolved parameters, column roles, before/after summaries, and a
  deterministic digest over canonicalised data and configuration.
- Summaries include rows, distinct runs, active protein groups, stripped
  peptides, modified peptidoforms, frozen evidence counts, current survivor
  counts, missing/non-finite values, imputed cells, decoys, and contaminants.
- Every removal ledger contains stable identity fields plus one or more exact
  reasons; aggregate count-only logging is insufficient.
- Raw imported data remains immutable and is linked to all derived analysis
  views by digest/parent state.
- Stage prerequisites are expressed as required data shapes and evidence, not a
  needlessly rigid UI order; incompatible repeated or out-of-order operations
  fail with actionable diagnostics.
- Audit artifacts contain no private source data beyond explicitly requested
  outputs and are reproducible from an input path plus recorded parameters.

## File-by-File Plan

- Add pure audit helpers for canonical summaries, identities, ledgers,
  parameter/column-role capture, and deterministic hashing.
- Extend `WorkflowState` additively with optional audit metadata while keeping
  existing `saveState()` callers and mocked signatures compatible.
- Have every peptide-QC and IQ-handoff apply step emit the same versioned audit
  schema, including skipped/no-op decisions.
- Define and test stage/data-shape contracts: confidence columns before frozen
  evidence, precursor identity before rollup, peptide identity thereafter, and
  active protein-key metadata at downstream handoff.
- Add a headless audit runner accepting arbitrary DIA-NN TSV, design/config,
  output directory, and optional contaminant manifest; never embed local data
  paths in package code.
- Add synthetic E2E/module-CI assertions plus optional hash-pinned closeout for
  the local cotton and KV files.
